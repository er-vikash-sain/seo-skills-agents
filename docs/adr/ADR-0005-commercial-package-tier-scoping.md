# ADR-0005: Commercial Package Tier Scoping Protocol

- **Status:** Accepted
- **Date:** 2026-07-28
- **Context:** Agency operations sell distinct service tiers (Plan 1 Baseline, Plan 2 Expanded, Plan 3 Full).
- **Decision:** Embed tier entitlement bounds directly into skill procedural logic, planner roadmaps, and integration test assertions.
- **Consequences:** Prevents scope creep and ensures client deliverables match purchased plan contracts.
