# ADR-0008: Multi-Engine GEO & AEO Unified Testing Model

- **Status:** Accepted
- **Date:** 2026-07-28
- **Context:** Generative search engines (ChatGPT, Perplexity, Gemini, Claude, Google AIO) present diverse citation mechanisms.
- **Decision:** Consolidate Knowledge Graph modeling, Answer Block formatting, and multi-engine citation evaluation into a single unified subagent context (`entity-geo`).
- **Consequences:** Prevents agent sprawl, unifies AI answer engine visibility metrics into a single cohesive strategy matrix.
